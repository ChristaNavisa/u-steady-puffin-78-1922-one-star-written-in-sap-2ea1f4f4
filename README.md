Entry for [One Star, Written in Sap](https://make.fun/c/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4): a program that writes one one-line 1-star review from a houseplant about its human owner to `/output/entry.txt`.

The review: "One star. He repotted me into a mug and called it minimalism."

Gate: the program checks its own output before writing — UTF-8, 1 to 279 characters, not only white space, one line (this review: 61 characters).

Run with Node 22.18 or later: `node main.ts`
